# bin2d 测试

## 怎么跑

```sh
make test        # 跑全部（失败非 0 退出）
make all         # 只构建
```

产物在 `build-mingw/out/tests/`。每个测试是一个独立可执行文件，输出 `PASS:` / `FAIL:` 行，
末尾打印 `=== <名字>: 全部通过 (N 项) ===` 或失败计数。

## 覆盖了什么

| 文件 | 断言 | 关键点 |
|---|---|---|
| `test_geometry.cpp` | 32 | Transform 复合/逆/往返/退化；Path 展平容差与弦高、精确包围盒、圆角半径夹紧、点在路径内；Rect 求交/向外取整/开区间 |
| `test_raster.cpp` | 14 | 整像素矩形**逐像素精确值**、覆盖率和 = 面积×alpha；圆面积误差 < 1.5%；45° 方块覆盖率面积误差 < 0.5% 且存在大量半覆盖像素；nonzero/evenodd（双圆环 + 五角星）；描边宽度 ±0.5、圆端帽多出半圆面积 |
| `test_composite.cpp` | 20 | 五种混合模式的手算期望值；组透明度 50%×50%=25% 且重叠区只混一次（37.5%）；路径裁剪边缘是覆盖率、restore 后恢复；图层套图层透明度连乘；矩形裁剪 |
| `test_scene.cpp` | 9 | **Scene 渲染 == Canvas 直接画逐像素相同**、重复渲染稳定；Group 变换 + 透明度；父 ∘ 子变换复合；投影落在偏移方向并压暗底色（区域平均） |
| `test_png.cpp` | 16 | 逐 chunk 解析 + 自算 CRC 对拍、chunk 顺序、IHDR 字段；同输入两次逐字节相同；反预乘（50% 白压黑 → `0xFF808080`）、alpha=0 → 0 |
| `test_gpu_bridge.cpp` | 3 | 可选：存在 `../binGPU/build-mingw/libbingpu.a` 才编。一帧 → bingpu CPU 后端 → `frame_read` → 与软件路径逐像素对照（容差 ≤1，实测 0） |

## 写测试的几条约定

- **能写精确值就写精确值**：整像素矩形、混合模式都断言精确字节，别用"差不多"的容差
  掩盖实现错误。
- **AA 不要考"相邻跳变"**：竖直方向只有 8 条子扫描线，一条近乎水平的边缘会在一行之内
  从 0 跳到 1（位置误差 ≤1/8 px）。要考就考**覆盖率面积**与"存在大量半覆盖像素"。
- **对比要能定位**：Scene vs Canvas 这类测试失败时先打印首个差异像素，别只报数量。
- **半像素偏置**：圆/方块的边正好压在像素边界上时覆盖率本来就是 0 或 1，
  测 AA 时把圆心挪半像素。
