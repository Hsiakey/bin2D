# 架构

> bin2d 是"2D 绘制核"：**不认节点、不认布局、不认文本、不认窗口**。
> 输入是路径/颜料/位图与一串变换，输出是一张预乘 RGBA8 位图。

## 分层

```
             ┌──────────────────────────────────────────────┐
 上层宿主 →  │ Canvas（即时）      Scene（保留）              │  这两层只做"状态/遍历"
             └───────────────┬──────────────────────────────┘
                             │  RasterTarget{surface, clip, mask, blend}
             ┌───────────────▼──────────────────────────────┐
             │ raster：覆盖率 AA + 合成（唯一的落像素出口）    │
             └───────────────┬──────────────────────────────┘
             ┌───────────────▼──────────────────────────────┐
             │ Path（命令 + 按需展平）  Paint（纯色/渐变/位图）│
             └───────────────┬──────────────────────────────┘
             ┌───────────────▼──────────────────────────────┐
             │ Surface（预乘 RGBA8 + stride）  Image / Transform│
             └──────────────────────────────────────────────┘
                             │  可选
             ┌───────────────▼──────────────────────────────┐
             │ gpu.h：Surface ⇄ bingpu 纹理（HEADLESS 往返）   │
             └──────────────────────────────────────────────┘
```

## 每层的职责与"为什么不合并"

| 层 | 职责 | 不合并的理由 |
|---|---|---|
| `Surface` | 位图内存 + 整像素操作 | 它必须能当渲染目标、能直接塞进外来缓冲（stride），这是"内存"的事 |
| `Image` | 只读素材 + 采样 + 九宫格参数 | 画布与素材的语义不同；合并会让"同一个图标画十处"像是十份位图 |
| `Transform` | 2×3 仿射（SVG matrix 语义） | 与 bingpu 的 `xf[6]` 只是顺序差，集中在一处转换 |
| `Path` | 命令级存储 + 展平 + 精确包围盒 | 展平结果与缩放比绑定，存折线会在大倍率下露多边形棱角 |
| `Paint` | 纯色 / 线性渐变 / 位图的采样规则 | 与形状正交：同一条路径要能用任意颜料 |
| `raster` | 覆盖率计算 + 合成 | 只有这一层写像素，所以"混合模式/裁剪/AA"永远只有一种实现 |
| `Canvas` | 变换栈 / 裁剪栈 / 图层栈 / 混合模式 | 即时模式的全部状态机 |
| `Scene` | 节点树 + 渲染遍历 + `version()` | 保留模式才有"内容没变"这个概念，是缓存的挂载点 |
| `gpu` | Surface ⇄ bingpu 纹理 | 可选依赖，缺库时整层不进库 |

## 数据流：一次 `canvas.fillPath(path, paint)`

1. **变换**：`deviceTransform()` 把局部矩阵与当前图层的原点偏移合成一张 `Transform`
   （层内坐标 = 设备坐标 − 层原点，见 `canvas.h` 的注释）。
2. **展平**：`path.flatten(tolerancePx / scale)`，容差按设备像素给，变换放大会自动细分得更密。
3. **覆盖率**：每像素行切 8 条子扫描线 → 与折线求交 → 按填充规则（nonzero/evenodd）
   取区间 → 区间端点的小数部分当水平覆盖率 → 本行求和 / 8。
4. **颜料**：像素中心反映射回局部坐标，取纯色/渐变/位图颜色，乘覆盖率。
5. **合成**：`BlendPixel(dst, src, blend)`，一条出口。

图层（`pushLayer`）额外插两步：分配一块离屏 `Surface`（尺寸 = 裁剪后的设备矩形）、
把之后的所有绘制打到它上面；`popLayer` 时整块乘 opacity 再按层的混合模式合成回来。

## 关键技术决定

- **预乘 RGBA8**：组透明度、图层合成在预乘空间里就是乘法；直通空间每次要除 alpha。
  代价是"写入"必须先乘 alpha（`Color::straight/argb` 一次到位），导出 PNG 前反预乘。
- **覆盖率 AA，不是模糊**：先算覆盖率再乘颜料，一个像素只混一次、混的是同一颜色的样本；
  先填色再模糊会从透明区渗色（深底浅形状时边缘发灰）。
- **8 条竖直子扫描线**：位置误差 ≤ 1/16 px、覆盖率误差 ≤ 1/8；水平方向解析求交，
  整像素对齐时覆盖率精确为 1（测试能写"逐像素精确值"就靠这条）。
- **描边走多边形并集**：每段四边形 + 连接块 + 端帽叠进同一张覆盖率（取 max），
  最后统一混合一次 —— 逐段各自混合会在接缝重复混、出现一条深缝。
- **图层用离屏，不用逐形状乘 alpha**：逐形状乘 alpha 时重叠区会被乘两次（叠深）。
